# LAB-7 - Galerie de Stars : RecyclerView, Animations et Filtrage

Une application Android moderne démontrant l'utilisation avancée du **RecyclerView**, le filtrage en temps réel et des interfaces utilisateur soignées avec **Material Design 3**.

## 🌟 Fonctionnalités
- **Affichage en liste** : Utilisation d'un `RecyclerView` avec des `MaterialCardView`.
- **Filtrage en temps réel** : Barre de recherche (`SearchView`) pour filtrer les stars par nom.
- **Notation interactive** : Pop-up (`AlertDialog`) permettant de modifier la note (étoiles) de chaque star.
- **Animations** : Écran de démarrage (Splash Screen) avec animation de rotation et de fondu.
- **Design Moderne** : Intégration de Material Design 3, Glide pour les images, et CircleImageView.

## 🛠️ Technologies utilisées
- **Langage** : Java
- **UI** : Material Design 3, ConstraintLayout, CardView
- **Bibliothèques** : 
    - [Glide](https://github.com/bumptech/glide) (Chargement d'images)
    - [CircleImageView](https://github.com/hdodenhof/CircleImageView) (Images circulaires)
- **Architecture** : Pattern DAO pour la gestion des données.

## 📸 Aperçu
L'application affiche une liste de célébrités où chaque carte est interactive. Le filtrage s'effectue instantanément lors de la saisie dans la barre de recherche.
